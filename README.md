# JECK Comprehensive College website

Website for JECK Comprehensive College, No 5 Jeck Close, off Oro-Igwe Road, Elimgbu, Port Harcourt.

`index.html` opens the 3D virtual tour, where visitors drive the JECK school bus to the school. The **Go to website** button leads to the main site (`home.html`): Welcome, Learning, School Life, Admissions, News, Alumni and Contact.
